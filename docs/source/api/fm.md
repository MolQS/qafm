# fm

The fm module handles all calculations that concern the frequency modulated case where $A=A_0$ and $\phi=-\pi/2$ are held constant by feedback loops. Observables are calculated within `observables`, conversions between different observables is offered by `conversions` and the inversion from measurement data to forces is available from `inversion`.
